# RH Media

RH Media — адаптивная социальная платформа с лентой публикаций и локальными функциями сообщества.

**Сайт:** https://raher458.github.io/MyMusic/

## Что доступно в текущей версии

- Локальная регистрация, вход и выход из аккаунта.
- Профили участников, редактирование имени, описания и фотографии профиля.
- Лента публикаций: текст, изображения, видео и аудио; реакции, комментарии, сортировка по популярности, просмотрам, лайкам и комментариям, редактирование и удаление своих публикаций.
- Поделиться публикацией через системное меню мобильного устройства или копирование ссылки с резервным способом для браузеров без Clipboard API.
- Подписки и отдельная лента подписок.
- Личные диалоги с историей сообщений и отметками прочтения.
- Уведомления о реакциях, комментариях, подписках и сообщениях.
- Раздел видео-предложений с локальной модерацией.
- Игровые комнаты и список участников.
- Локальная панель администратора и инструменты модерации.
- Экспорт и импорт резервной копии в JSON.
- Настройки уведомлений: звук, лайки, комментарии, подписчики и личные сообщения.
- При импорте резервной копии проверяется структура и допустимые значения настроек уведомлений; некорректные данные отклоняются до замены локального хранилища.
- Адаптивный интерфейс для мобильных устройств и компьютеров.

## Важное ограничение текущего режима

Сейчас клиент работает в локальном режиме. Аккаунты, публикации, подписки, сообщения, уведомления и игровые комнаты сохраняются в `localStorage` текущего браузера.

Это означает:

- Данные не синхронизируются между разными устройствами или браузерами.
- Разные посетители сайта не получают общую ленту и общие диалоги.
- Очистка данных браузера может удалить локальные данные. Для переноса используй экспорт резервной копии.
- Роли и административные права в локальном режиме не являются серверной защитой: данные браузера можно изменить вручную. Не используй локальную админ-панель для управления реальным публичным сообществом.

Для полноценной многопользовательской платформы необходимо отдельно подключить серверную авторизацию, базу данных, хранение медиа и серверную проверку прав доступа. Серверные файлы в рамках текущего этапа не изменялись.

## Резервные копии

Открой **Настройки → Резервная копия**:

1. Нажми «Скачать», чтобы сохранить JSON-файл с локальными данными RH.
2. Для восстановления выбери ранее сохранённый файл.
3. Импорт заменяет локальные данные в текущем браузере. Перед подтверждением убедись, что у тебя есть нужная резервная копия.

Максимальный размер файла резервной копии — 10 МБ.

Файл содержит локальные профили, хеши паролей и данные сессии. Храни его приватно и не отправляй посторонним.

## Структура проекта

- `index.html` — HTML-точка входа и подключение ресурсов.
- `app.js` — клиентская логика RH Media.
- `styles.css` — оформление и адаптивная вёрстка.
- `worker.js`, `wrangler.toml`, `schema.sql`, `migrations/` — отдельная серверная часть. Эти файлы не входят в локальные изменения интерфейса.

## Публикация

Проект публикуется через GitHub Pages из основной ветки `main`. После коммита GitHub запускает сборку и публикацию сайта.
- Локальные реакции на публикации нормализуются: повторяющиеся и некорректные идентификаторы участников отбрасываются, а реакция не записывается для отсутствующей публикации.
- Комментарии проверяются при открытии и изменении: повреждённые списки не приводят к падению интерфейса, а редактирование и удаление доступны только автору комментария.
